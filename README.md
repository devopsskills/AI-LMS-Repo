# Daylist

A simple, focused to-do list built with plain HTML, CSS and JavaScript. No build step or dependencies.

## Features

- Add tasks (up to 120 characters)
- Mark tasks as done
- Filter by All, Active or Done
- Clear completed tasks
- Tasks are saved in your browser's `localStorage`, so they persist across reloads

## Getting started

Clone the repo and open `index.html` in a browser:

```bash
git clone https://github.com/devopsskills/AI-LMS-Repo.git
cd AI-LMS-Repo
```

## Project structure

| File         | Purpose                                  |
| ------------ | ---------------------------------------- |
| `index.html` | Page markup                              |
| `styles.css` | Styling                                  |
| `script.js`  | Task logic, filtering and persistence    |
